# GridSentinel design context

Compact industrial monitoring console. Light operational surfaces, persistent navigation, thin separators, technical units and functional tables. No promotional hero, decorative image assets, gradients, watermarks or generator branding.

Colors: background #F5F6F7, surface #FFFFFF, text #20252B, secondary #68727D, accent #275D78, border #DCE1E5, critical #B64545, warning #B47D2B, healthy #39765A.

Typography: locally available Inter/Segoe UI for interface labels, Consolas/IBM Plex Mono for station IDs and time values. No remote font dependency.

Charts: solid actual demand, amber reported demand, dashed grey baseline; no animated chart traces. Power comes from computed simulation states. Browser mode is explicitly labeled.

Navigation remains available on desktop and collapses into a keyboard-operable menu on narrow screens. Tables scroll horizontally; form grids collapse before controls overlap.
